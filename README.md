# TideGlyph

TideGlyph is a quiet field notebook board for coastal research teams. Track what is in each survey, mark pieces as logged, filter by species or priority, and keep a batch selected while you move between views.

## Getting started

    npm install
    npm run dev

Useful checks:

    npm test
    npm run typecheck
    npm run build

Data is saved locally in the browser. No network or account is required.
